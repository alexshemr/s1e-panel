Число, выбор, текст

Три простые карточки для вспомогательных сущностей Home Assistant: input_number / number (уставка бойлера, громкость), input_select / select (режим дома) и input_text / text (сообщение на панели). Число меняется кнопками − и + или слайдером, смотря какой mode у сущности. Выбор показывается кнопками, если все варианты помещаются, а если нет — текущим вариантом со стрелками и точками. Текст пока только показывается. Дата и время — на отдельном стенде «Время».
